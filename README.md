# Website — TCC

Frontend web em React, TypeScript e Vite.

## Iniciar

```bash
npm install
npm run dev
```

## Organização

- `src/pages`: páginas da aplicação
- `src/components`: componentes reutilizáveis e layout
- `src/routes`: rotas
- `src/services`: integração com APIs
- `src/hooks`, `src/types`, `src/styles`, `src/assets`: recursos compartilhados
