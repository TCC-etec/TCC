# App mobile — TCC

Aplicativo em React Native com Expo e TypeScript.

## Iniciar

```bash
npm install
npx expo start
```

## Organização

- `src/screens`: telas
- `src/components`: componentes reutilizáveis
- `src/navigation`: navegação
- `src/services`: integração com APIs
- `src/hooks`, `src/types`, `src/theme`: recursos compartilhados
